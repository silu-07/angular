## How to Add Custom Songs

1. Place your `.mp3` files in this directory
2. Update the playlist in `src/app/app.component.ts` with the corresponding filenames
3. The player will automatically load and play them

**Note:** Make sure filenames match exactly with the URLs in the component. Use lowercase and hyphens for spacing.
